# UPSC Defence Exam Intelligence

An evolving data and AI project for analysing historical UPSC defence examination papers, beginning with CDS and CAPF Previous Year Questions (PYQs).

## 🎯 Project Objective

The objective of this project is to transform historical UPSC defence examination questions into a structured, analysable dataset and progressively build an intelligence system that can identify:

* Subject and topic-wise question patterns
* Frequently tested concepts
* Recurring topics and questions
* Year-wise trends
* Difficulty patterns
* Cross-examination similarities
* Data-driven preparation insights

The project will evolve as new technical skills are added, including Python, SQL, Power BI, APIs, AI/NLP and automation.

## 📚 Examinations Covered

The project will initially focus on:

* Combined Defence Services (CDS)
* Central Armed Police Forces (CAPF)

Additional UPSC defence examinations may be added in later stages.

## 🛠️ Technology Roadmap

The project will progressively incorporate:

* Excel / CSV — Initial data structuring and validation
* Python — Data extraction, cleaning, analysis and automation
* SQL — Database design and analytical queries
* Power BI — Interactive dashboards and visualization
* APIs — Automated data ingestion
* AI / NLP — Question classification, topic intelligence and semantic analysis
* Automation — End-to-end data processing and reporting

## 📈 Project Philosophy

This is intended to be a continuously evolving portfolio project rather than a one-time analysis.

The project will begin with simple data collection and analysis and progressively incorporate more advanced capabilities as new skills are learned.

The long-term goal is to demonstrate an end-to-end ability to:

**Collect → Structure → Clean → Analyse → Visualize → Understand → Predict/Recommend → Automate**

## ⚠️ Data & Sources

The project will use publicly available examination information and appropriate derived/structured data.

Original source material will be referenced where applicable. Copyright and data-reuse considerations will be respected when publishing material to this repository.
